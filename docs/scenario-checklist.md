# 화면 점검표

`scripts/e2e.ts` 가 실제 브라우저로 화면을 처음부터 끝까지 눌러 보고 적은 결과다. 손으로 고치지 않는다.

- 마지막 실행: 2026년 10월 9일 오전 10:34
- 결과: 113개 가운데 통과 113개, 실패 0개
- 대상: 개발 컴퓨터의 서버와 모의 운항. 배포 주소에서 코드를 넣은 뒤의 화면(키오스크, 직원)은 사람이 따로 확인한다.
- 카메라 QR 스캔은 패스 QR 그림을 가짜 카메라 영상으로 넣어 확인한다. 실물 스티커와 실제 조명, 스티커 프린터 출력은 다루지 않는다.
- 길과 시설 위치는 시연용 모의 자료다 (src/lib/airport.ts).
- "접근성 자동 점검"은 axe-core 로 WCAG 2.2 AA 까지의 규칙을 화면마다 돌린 것이다. 대비·이름표·역할 같은 것만 잡으며, 화면 읽기 프로그램으로 실제로 써 보는 것을 대신하지 않는다.

다시 돌리는 방법은 `scripts/e2e.ts` 맨 위에 적혀 있다.

## 여객 휴대전화: 패스

- [x] 패스 화면에 내 항공편과 탑승구가 나온다
- [x] 탑승 마감까지 남은 시간에 '추정'이 붙는다
- [x] 패스 화면에 고른 안내가 나온다
- [x] 패스 화면도 큰 글씨로 열린다
- [x] 화면을 저장해 두라고 알려 준다
- [x] 어디에도 이름이 없다
- [x] 주소의 ?new=1 은 바로 지워진다 (저장한 주소에 붙지 않는다)
- [x] 접근성 자동 점검: 휴대전화-내패스
- [x] 패스 화면을 닫았다 다시 열어도 같은 QR 이 나온다 (주소가 곧 패스)
- [x] QR 에 든 대문자 주소(/P/…)로도 같은 패스가 열린다 (휴대전화 기본 카메라로 찍은 경우)

- [x] 여객이 직접 등록을 지울 수 있다

- [x] 없는 패스 주소는 '등록된 패스가 아닙니다'라고 나온다

- [x] 접근성 자동 점검: 휴대전화-영어패스

## 키오스크 설치

- [x] 설치하지 않은 기기에서 키오스크 화면을 열면 설치 화면으로 간다
- [x] 접근성 자동 점검: 키오스크-설치
- [x] 안내 키오스크는 보안검색 뒤의 자리만 고를 수 있다
- [x] 직원 접속 코드로는 키오스크를 설치할 수 없다
- [x] 설치 코드와 자리를 넣으면 안내 키오스크가 된다
- [x] 키오스크가 된 기기로는 직원 화면을 열 수 없다

- [x] QR 값만 아는 기기(휴대전화)에는 길과 시설을 주지 않는다. 항공편과 고른 항목만 준다
- [x] 어느 응답에도 이름이 없다
