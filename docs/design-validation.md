실제 운영 시스템/장비 연결과 실물 스캔은 검증하지 않았다. 오류 경계의 이미지는 실제 오류 컴포넌트를 격리 렌더링한 결과이며 장애 복구 통합 검사를 의미하지 않는다. 자동 접근성 통과는 화면 읽기 도구를 이용한 사용자 평가를 대신하지 않는다.

## 통합 PR
1~3단계와 별도 화면 개편은 이미 main에 포함되어 있다. 이를 상속한 통합 결과를 main 기준 PR 하나로 제출한다. 이번 차이는 모션·인쇄·최종 검증이며 화면 구성 파일은 main과 동일하다. `design-main-preservation.json`에 13개 보호 파일과 6개 스타일 파일의 배치 속성 비교를 기록한다.

main의 500 오류 수정(design-theme 상수 및 일치 검사)을 보존했다. 기존 글자 크기 예외 9곳은 이번 단계에서 재배치하지 않기 위해 main 그대로 유지하며, 새 글자 예외는 허용하지 않는다.

배치 보존 검사는 화면의 display/grid/flex/정렬/간격/위치/너비/높이와 글자 크기·굵기·행간을 비교한다. 인쇄 및 고대비는 별도이며, 축소 설정에서 조작 영역을 유지하는 최소 44px/64px 값은 접근성 보정 예외다.

사전등록의 언어 버튼(40px)과 축소 설정의 일부 버튼은 main 레이아웃에서 권장 44px보다 작다. 자동 WCAG AA 검사와 구별해 preferred44pxWarnings로 보고한다. 별도 레이아웃 작업을 덮어쓰지 않기 위해 이 단계에서 고치지 않았다. 모션의 진입 중 투명도를 최종 글자 대비로 잘못 판단하지 않도록 유한 애니메이션 종료 후 axe를 실행한다.

0.9배 구체 값: 소리로 듣기 너비 39.59px/높이 44px, 한국어·English 높이 36px. 기본 언어 버튼 높이는 40px다. 권장 44px와 비교한 값이며 main의 구성 파일은 수정하지 않았다.

최종 화면 행렬: 개선 후 161개, 원본 대응 159개(부품 전시장 2개 추가). 가로 넘침·pageerror·500 응답·갤러리 이미지 누락 각각 0. 경로/너비 필터 동작 확인. 실제 흐름 화면 63장도 최종 E2E로 갱신했다. Vercel 미리보기의 실제 렌더링 결과는 배포 후 PR 본문과 로컬 GPT 작업내역/전면디자인/preview에 기록한다.
