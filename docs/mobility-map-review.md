# 이동지원 지도 통합

작업 전 최신 main을 다시 pull하여 6107ae3(PR #66, 홈 배치 수정)을 병합하고 기존 지도 변경을 복원했습니다. 다른 팀원의 홈 화면 코드는 수정하지 않습니다.

## 변경

이동지원의 별도 현재 위치 검색과 목적지 지도를 하나의 출발지·현재 위치 버튼·목적지·지도 흐름으로 묶었습니다. 공통 FacilityMapPicker를 사용해 시설 분류 필터, 통로 거리 기반 가까운 후보 3곳, 목적지 선택 시 경로·거리 표시를 동일하게 적용합니다.

출발지는 기존 운영·배정 시스템에 등록된 만날 탑승구를 지도에서 선택합니다. 임의 시설을 가장 가까운 데스크로 바꿔 저장하지 않습니다. 선택한 탑승구의 실제 기존 placeId를 그대로 저장합니다. 키오스크의 수동 출발지 변경은 등록된 기기와 같은 터미널·보안구역에서만 허용하며, 서버에서도 다시 검증합니다. 다른 서비스의 키오스크 위치 고정 정책은 유지합니다.

출발지를 바꾸거나 현재 위치로 복원할 때 목적지가 여전히 같은 구역의 유효한 시설이면 유지하고 경로를 다시 표시합니다. 다른 구역이 되면 목적지를 비웁니다. 목적지는 선택 사항으로 남으며, 휠체어 수령 전용 요청은 만날 곳만 선택합니다.

현재 위치가 3층 지도와 연결되지 않은 경우 기존 목록·사진 위치 찾기 경로를 제공합니다. 위치를 임의의 좌표로 바꾸지 않습니다. 현재 위치는 전달받은 등록된 기기 위치이며 GPS나 실제 로봇 실시간 위치 수신은 포함하지 않습니다.

키오스크 이동지원 작업면은 기존 devices.css에서 최대폭을 해제하고 요청 요약을 아래에 두는 한 열 구성으로 바꿔 지도 가로폭을 확보합니다. 기존 지역 지도 스타일과 디자인 토큰을 재사용합니다. layout.tsx에 CSS를 덧붙이지 않습니다.

## 확인

- 타입 검사 및 ESLint 오류 없음. 기존 StampBook 이미지 경고 2개.
- 전체 테스트 992개 통과, 5개 건너뜀.
- Next.js 빌드 성공.
- 브라우저의 실제 MobilityMapPlanner에서 기기 출발지 유지, 화장실 후보 46/101/187m 추천, 목적지 ID 설정, 약 46m 경로 자동 표시 확인.
- 320/390px 휴대전화와 1280px 키오스크를 글자 1/1.5배로 확인. 가로 넘침 없음.
- 서버 테스트에서 키오스크 수동 출발지·시설 목적지 저장 및 재조회 확인. 다른 터미널·보안구역·미등록 출발지는 거절 확인.

브라우저 확인은 해당 컴포넌트 검증 화면이며 전체 실제 서비스 검증은 아닙니다. scripts/layout-check.ts와 scripts/e2e.ts 전체 흐름 및 Vercel 미리보기 검사는 별도로 필요합니다. DB 구조 변경은 없습니다. 기존 지도 자료의 출처·이용 조건 문서는 유지합니다.
