# 장비 가용 현황 및 배차 연결

통합 요청의 담당 구역 배정에 더해, 로봇·이동지원 장비를 요청에 연결하는 내부 배차 기능을 추가한다. 실제 장비 제어는 모의 시연으로 유지한다.

## 동작
- 직원 메뉴의 통합 요청에서 ‘장비 현황 · 배차’로 이동한다.
- 안내데스크는 시범 장비의 이름·종류·기준 구역을 등록하고 가용·점검 중·운영 중지 상태를 관리한다. 장비는 자동으로 생성되지 않는다.
- 담당 배정 후 출발하기 전에 안내데스크 또는 담당 구역이 같은 서비스의 가용 장비를 배차하거나 해제한다.
- 같은 장비를 여러 진행 요청에 배차하지 못하도록 DB의 유일 인덱스와 잠금으로 보호한다. 장비 상태 변경도 같은 장비 행의 잠금으로 배차와 조정한다.
- 배차·해제는 요청의 버전을 변경하고 기존 처리 이력에 기록한다. 이력 기록 실패 시 배차도 되돌아간다.
- 담당 인계 시 배차를 유지한다. 출발 후에는 장비를 임의로 바꾸지 못한다.
- 배정 해제 시 장비 연결을 해제한다. 완료·취소·지원 불가·시간 초과된 요청은 장비의 활성 배차에서 제외되어 수량을 반환한다.
- 통합 요청과 오늘 현황에 종류별 현재 가용·배차·점검/중지 수량을 표시한다.

## 범위
- 장비 대장은 시범 운영용 내부 기록이다. 실제 장비 위치나 상태를 자동 수신하지 않는다.
- 장비 없이 진행하는 기존 이동 단계는 계속 모의 시연이며, 화면에 미배차를 명시한다. 장비를 선택하면 내부 배차 수량에 실제로 반영한다.
- 기존 호출·이동지원 원본에는 장비 배차를 소급 적용하지 않는다. 새 통합 요청에서 사용한다.
- 기준 구역은 보관·관리 구역이며 자동 경로 계산이나 이동 가능 구역 판정을 뜻하지 않는다.
- 실제 장비 통신, 위치·배터리·고장 수신, 운행 가능 경로, 자동 배차, 여객별 필요 장비 수·수용 인원 판정, 백그라운드 알림 수신 확인은 남아 있다.

## 검증
- 동시 배차, 배차와 점검 전환 경쟁, 담당 구역 권한, 상태·서비스·버전 검증, 완료·취소·시간 초과·지원 불가·재배정 후 반환, 담당 인계 시 유지, 이력 실패 시 롤백을 검사한다.
- 브라우저에서 장비 등록→배차→완료, 다른 요청의 장비 선택 제한, 점검 상태, 취소 후 반환, 모바일 및 접근성을 확인한다.
