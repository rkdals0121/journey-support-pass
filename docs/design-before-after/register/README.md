# 사전등록 `/register` 단계 화면 정리 (웹)

기준 화면은 웹 첫 화면(`/`)이다(`docs/ui-guide.md`). 이 PR 은 웹(`html:not([data-kiosk])`)에만 적용한다. 키오스크(`html[data-kiosk]`)의 배치와 노란 버튼은 그대로 뒀다.

## 바꾼 것
- 끝선: 진행 막대와 카드의 좌우 끝을 위쪽 바와 같게 했다(1333 폭에서 13–1306). 전에는 카드가 단계 목록 칸 옆에 안쪽으로 들어가 있었다(322–1294).
- 왼쪽 단계 목록과 오른쪽 요약 칸은 웹에서 두지 않았다. 몇 번째 질문인지는 위쪽 진행 막대(「n/9」)가, 앞 단계 고치기는 확인 화면의 「고치기」(`.review-edit`)가 같은 일을 한다.
- 질문 제목은 카드 맨 위의 노란 그라데이션 띠로 바꿨다(첫 화면 소개 박스와 같은 그라데이션). 별도 박스가 아니라 **카드 안쪽 윗부분 띠**다: 카드 안 내용이 `.flow-body > .choices` 같은 직접 자식 규칙에 기대고 있어, 내용을 감싸는 마크업을 바꾸지 않고 CSS 만으로 맞췄다.
- 주요 버튼(「다음」「동의하고 계속」「등록하기」)을 노랑에서 딥그린으로 바꿨다. 노란 버튼 규칙은 `html[data-kiosk]` 로 좁혀 키오스크는 그대로다.
- 선택 칸의 아이콘에 아이콘 칩(`--color-primary-faint`)을 넣었다. 선택지 목록은 2열로 늘렸다(걷기·보기 같은 긴 단계가 한 화면에 들어가도록).
- 낮은 화면(`max-height: 700px`)에서는 제목 띠 여백과 동의 화면의 줄 간격을 줄였다.
- CSS: 새 규칙은 사전등록 배치 파일(`responsive-passenger.css`)과 기존 `.flow-pretrip` 규칙이 있던 `passenger.css`·`sunflower.css` 안에서 고쳤다. 새 CSS 파일, `!important`, 색 코드, 고정 px 없음. 3칸·2칸 배치와 제목 최소 높이 규칙은 `html[data-kiosk]` 전용으로 좁혔다.

## 크기별 실측 (단계 9개를 끝까지 넘기며 단계마다 잼, 바꾸기 전 → 뒤)
「스크롤 있는 단계」는 페이지 전체나 카드 안이 스크롤되는 단계 수, 「끝선 어긋난 단계」는 카드 좌우 끝이 위쪽 바와 다른 단계 수다. 옆 넘침은 모든 크기에서 없다.

| 크기 | 스크롤 있는 단계 | 끝선 어긋난 단계 |
|---|---|---|
| 390×844 | 5 → 4 | 해당 없음 |
| 1280×633 | 6 → 0 | 9 → 0 |
| 1333×750 | 1 → 0 | 9 → 0 |
| 1366×657 | 5 → 0 | 9 → 0 |
| 1920×937 | 0 → 0 | 9 → 0 |
| 768×1024 | 재지 않음 → 0 | 재지 않음 → 0 |

- 원자료: `measure-before.json`, `measure-after.json`(단계별 doc/vh, 카드 스크롤 높이/보이는 높이, 바·카드 좌우 끝).
- 걷기·보기·듣기·안내 이해하기·아이와 함께 가기를 모두 고른 경우(14단계)는 1280×633, 1333×750, 1366×657 에서 「걷기」(1280×633만)와 마지막 확인 화면이 카드 안에서 스크롤된다. 긴 목록이라 허용 범위로 봤다.

## 점검
- tsc 통과, eslint 오류 0(경고 3개는 기존), vitest 1010 통과·5 건너뜀
- layout-check: 132개 화면, 문제 0개
- e2e: **끝까지 못 돎.** 통과 264 / 실패 0 에서 `/kiosk/entry` 탑승권 단계(`scripts/e2e.ts` 1531행)가 멈춘다. 변경 없는 `main` 에서도 같은 자리에서 멈춘다(통과 264). 사전등록 구간(여객 휴대전화 등록)은 그 앞이라 통과했다. 그 뒤 구간(안내로봇, 키오스크 등)은 돌지 못했다.

## 남은 문제
- 키오스크 사전등록(`/kiosk/guide` 안의 같은 흐름)은 CSS 를 `html[data-kiosk]` 로 좁혀 두었지만, 키오스크 상태에서 재지 않았고 e2e 로도 확인하지 못했다.
- 휴대전화(390)는 4개 단계가 스크롤된다(허용 범위).
- 글자 1.5배, 오류 화면, 영어 화면은 재지 않았다.
- 제목 띠는 「소개 박스」가 아니라 카드 안 윗부분 띠다(위 설명 참고).
