# 기기 소개 `/devices`, `/devices/[device]` 정리

기준 화면은 웹 첫 화면(`/`)이다(`docs/ui-guide.md`).

## 바꾼 것
- `/devices`
  - 머리글(`.public-page-heading`)을 첫 화면과 같은 소개 박스(`.ph-hero`)로 바꿨다. 안내로봇 그림은 소개 박스의 그림 자리에 둔다.
  - 기기 카드를 첫 화면 카드 모양으로 바꿨다: 흰 바탕, 1px 선, 아이콘 칩, 이름 한 줄, 보조 한 줄. 카드 위의 큰 그림 칸은 뺐다.
  - 「화면 미리보기」는 딥그린 주요 버튼이다. 아래에 따로 있던 「설치 코드 필요」 줄은 카드 속 「이 기기에 설치(직원 코드)」로 합쳤다.
  - 두 카드는 높이가 같다(노트북 204/204).
- `/devices/robot`, `/devices/kiosk`
  - 자체 머리(상태 줄 + 브랜드 줄 + English 단추)와 바닥 줄 대신 공용 위쪽 바·아래쪽 바(`PublicShell`)를 쓴다. 언어·글자 크기는 위쪽 바에 있다.
  - 소개 박스 한 개에 기기 이름, 질문(「어떤 서비스를 이용하시겠어요?」), 「기기 목록」「현장 기기에 설치」 링크를 담았다. 두 번 나오던 「기기 목록」은 한 번만 둔다.
  - 서비스 카드는 첫 화면의 `.ph-list` 카드를 그대로 쓴다. 「예약정보로 항공편 불러오기」도 같은 카드로 바꿨다.
  - 로봇 미리보기는 좁은 세로 틀(위쪽 바 없음, 넘친 부분은 잘림)에서 같은 틀로 바꿨다.
- CSS
  - 새 규칙은 `devices.css`의 기기 소개 묶음(`.dv-*`)에 썼다.
  - 첫 화면 규칙 중 아이콘 칩과 아래쪽 바 줄이기 규칙에는 `.dv-*` 선택자를 더했다(`passenger-layout.css`, 같은 규칙을 두 번 정하지 않음).
  - 쓰이지 않게 된 옛 규칙(`.device-card`, `.device-preview-*`, `.task-device-preview`, `.kiosk-task-heading` 등 92줄)은 지웠다.
  - 새 CSS 파일, `!important`, 색 코드, 고정 px, `overflow: hidden` 은 쓰지 않았다.
- `scripts/device-layout-e2e.ts`: 「세로 틀 안 카드」 점검을 「카드 격자 안·같은 높이」 점검으로 바꿨다. 이 스크립트는 Windows Chrome 경로로 되어 있어 이 PR 에서는 돌리지 않았다.

## 남은 문제
- 글자 1.5배: 노트북(1280×633, 1333×750, 1366×657)과 1024×768에서 스크롤이 남는다. 1920 폭은 스크롤 0이다.
- 휴대전화는 한 줄 배치라 세로가 길다. 전 미리보기는 세로 틀이 잘려서 844였고, 지금은 잘리지 않아 1046~1235다.
- 세로 1080×1920은 스크롤은 0이지만 카드 아래 빈 곳이 크다.
