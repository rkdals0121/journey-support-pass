# 시연 `/demo/booking`, `/demo/boarding` 정리

기준 화면은 웹 첫 화면(`/`)이다(`docs/ui-guide.md`).

## 바꾼 것
- 두 화면 모두 위쪽·아래쪽 바가 없는 맨 화면이었다. 이제 공용 틀(`PublicShell`)을 쓰고, 본문 끝선은 위쪽 바와 같다(`.task-home`).
- `/demo/booking`
  - 소개 박스(`.ph-hero`) 하나에 시연 안내 한 줄, 「항공권 예매가 완료되었습니다」, 「첫 화면으로」, 여정 정보(여정·출발·예약번호·탑승객)를 담았다.
  - 그 아래에 같은 높이의 카드 두 장을 둔다. 왼쪽은 「공항에서 필요한 도움이 있으신가요?」와 딥그린 버튼이고, 오른쪽은 「예약 확인 문자」 말풍선과 다른 접점 한 줄이다.
  - 두 줄짜리 설명과 안내 문단을 한 줄로 줄였다(한국어·영어). e2e 가 찾는 문구(「공항에서 필요한 도움이 있으신가요?」「시연용 모의 화면」「예약 확인 문자」「필요한 도움 미리 알려 두기」)와 링크 주소는 그대로다.
- `/demo/boarding`
  - 세 문장짜리 시연 안내를 소개 박스의 한 줄로 바꿨다. 제목 「모의 탑승권 만들기」와 짧은 설명 한 줄을 함께 둔다.
  - 아래는 두 칸이다. 왼쪽 카드는 편 검색, 편 목록, 「새 탑승권 번호로」「다른 편 고르기」이고, 오른쪽 카드는 탑승권이다. 편을 고르기 전에는 「편을 고르면 여기에 탑승권이 나와요」가 나온다.
  - 탑승권은 태블릿·노트북에서 가로로 놓는다(왼쪽 편 정보, 오른쪽 QR). QR 크기는 화면 높이에 비례한다(`clamp(7rem, 22dvh, 13rem)`).
  - 검색칸 돋보기가 입력 글자와 겹치던 문제는 아이콘을 카드의 아이콘 칩으로 옮겨 없앴다.
- CSS
  - 새 규칙은 여객 웹 배치 파일(`passenger-layout.css`)의 시연 묶음(`.dm-*`)에 썼다.
  - 쓰이지 않게 된 `passenger.css`의 `.booking-demo`·`.booking-card`·`.booking-link`·`.booking-sms` 9줄은 지웠다.
  - 새 CSS 파일, `!important`, 색 코드, 고정 px, `overflow: hidden` 은 쓰지 않았다.

## 남은 문제
- 글자 1.5배에서는 노트북과 1024×768에서 스크롤이 남는다.
- `/demo/boarding`은 원래 한국어 전용이다. 위쪽 바의 EN 을 눌러도 본문은 한국어다(영어 문구는 이번에 더하지 않았다).
- 휴대전화는 한 줄 배치라 세로가 길다(1245, 1357).
