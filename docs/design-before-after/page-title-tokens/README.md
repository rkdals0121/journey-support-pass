## 미완료·측정 한계

- `/prepare`의 큰 소개 제목은 내용 페이지 제목과 역할이 달라 40/56px 예외로 유지합니다.
- 안내 기기 안 등록 화면은 기존 루트 글자 정책 때문에 공통 토큰을 써도 실제 제목이 28/42px입니다. 일반 키오스크의 45.5/68.25px와 아직 다릅니다. 루트 정책을 바꾸는 시도에서 본문 661px에 내용 1470px가 생겨 되돌렸습니다. 이 PR은 초안이며 병합하면 안 됩니다.
- 전체 자료의 안내 첫 화면은 앞 여객 설정을 초기화합니다. 요청한 1.5배가 실제로 1배로 초기화된 기록을 1.5배 검증으로 세지 않습니다. 별도 embedded 자료만 실제 설정 창에서 배율을 바꿨습니다. 안내 첫 화면의 세로 기기 1.5배 추가 촬영은 완료하지 못했습니다.
- 기존 `/kiosk/visits` 1.5배 문서 넘침(1920에서1293, 1024에서887, 1080에서2103px)은 이 작업 전에도 존재합니다. 배치 검사 문제 0개와 모든 문서 스크롤 0은 같은 뜻이 아닙니다.
- 운영자 설치 화면 `/kiosk` 1333×750의 전체 높이는 898→914px입니다. 긴 설치 폼을 숨기지 않았습니다.
- 상단 바·지도 끝선·카드 재디자인은 바꾸지 않았습니다. #114와 겹치는 작업은 보류합니다.

## 최종 검사와 추가 큰 글자 실측

- tsc 오류 0, eslint 오류 0·기존 경고 3개, vitest 1015 통과·5 건너뜀.
- 전체 E2E는 289개 중 288개 통과, 1개 실패입니다. 실패: 입구로봇-통합배정 `color-contrast .public-button`. 별도 PR #115가 고치는 기존 대비 항목이며 이 독립 제목 갈래에는 그 변경을 섞지 않았습니다.
- 실제 설정 창으로 안내 첫 화면 1.5배를 켠 추가 실측: 1920×1080은 제목 97.5→68.25px, 문서 2862→2827px. 1024×768은 제목 47.25→47.25px, 문서 1660→1660px입니다. 원래의 큰 세로 넘침이 남습니다. 추가 측정의 변경 전 사진은 같은 화면에서 제목 규칙만 기존 값으로 복원한 CSSOM 비교입니다.
- 안내 첫 화면 1080×1920의 실제 1.5배 추가 측정은 완료하지 못했습니다(재지 않음). 도장 획득·사진 필터 등 모든 스탬프 후속 상태의 전·뒤 시각 실측도 재지 않음입니다.
- 최종 layout-check: 216개 화면, 문제 0개. 검증용 복제본과 소스 13개 파일의 해시가 E2E 전·뒤 모두 일치했습니다.
