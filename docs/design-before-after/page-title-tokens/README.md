기준은 최신 main a69f316(#115·#117·#118 포함)입니다. 실제 Chrome에서 CSS px로 측정했습니다. 사진과 표는 이 기준으로 다시 만들었으며 이전 초안의 실측 자료를 대체합니다. 임시 측정 스크립트와 큰 JSON은 저장소 밖에 보관합니다.

## 범위와 예외

- 일반 쪽 제목은 tokens.css의 `--text-page-title`을 사용합니다. 새 색·CSS 파일·vw 글자 크기를 추가하지 않았습니다.
- 첫 화면·사전등록 소개·하늘이 소개는 안내의 중심이 되는 큰 제목이므로 기존 hero 크기 예외를 복원했습니다. 일반 쪽 제목을 맞추기 위해 소개 제목을 줄이지 않습니다.
- 안내 기기 안 등록 제목 맞춤은 기존 루트 글자 크기 정책을 바꾸지 않고는 해결할 수 없어 해당 항목을 중단했습니다. 일반 키오스크는 화면에 따라 루트 18/26px, 등록 화면은 16px이며, 같은 1.75rem 토큰이 각각 31.5/45.5px와 28px가 됩니다. 1.5배에서는 각각 47.25/68.25px와 42px입니다. 화면별 보정값이나 vw 글자 크기를 추가하지 않았습니다. 루트 배율 변경 실험에서 본문 661px에 내용 1470px가 생겨 809px 넘쳤으므로 루트 정책과 등록 배치는 유지했습니다.

## 겹치는 규칙 정리

- 등록 제목의 글자·줄높이·자간·줄바꿈은 responsive-passenger.css의 원래 제목 규칙 한 곳으로 모았습니다. passenger.css와 site-bar.css의 덮는 제목 규칙은 제거했습니다. 같은 토큰을 반복하던 미디어 규칙의 글자 크기 재선언도 제거했습니다.
- 정리 전·뒤 18개 조건에서 제목/소개 띠/본문/진행 버튼 줄의 글자 크기·굵기·줄높이·자간·줄바꿈·위아래 여백과 안쪽 여백, 사각형 위치·크기, client/scroll 높이를 비교했습니다. 차이 0개입니다.
- 웹 390·1333·1920은 불편 선택/동의 × 글자1/1.5배, 안내 기기 1920×1080·1024×768·1080×1920은 불편 선택 × 실제 설정1/1.5배입니다. 마지막 1920 웹 비교는 움직임 줄이기로 전환 모션을 제거하고 다시 쟀습니다.
- 지도 모듈의 모바일·로봇 제목 중복 선언도 제거했습니다. 기본/로봇 × 390·1333·1920 × 글자1/1.5배의 12개 조건에서 계산된 모양 차이 0개를 확인했습니다.
