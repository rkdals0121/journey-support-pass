# 기기 점검 `/check` 화면 정리

기준 화면은 웹 첫 화면(`/`)이다(`docs/ui-guide.md`).

## 바꾼 것
- 위쪽·아래쪽 바가 없던 화면을 `PublicShell` 안에 넣었다(다른 여객 웹 화면과 같은 틀).
- 소개 박스(`.ph-hero`) + 점검 카드 격자(`.dc-grid`)로 바꿨다. 카드는 흰 카드 + 아이콘 칩, 나란한 카드 높이는 같다(`grid-auto-rows: 1fr`). 6개 점검 + 점검용 QR + 키오스크 설치 링크 = 카드 8개, 태블릿 이상은 4열 × 2줄.
- 글을 줄였다: 소개는 한 줄, 정상일 때의 상태 글은 한 줄. 문제가 있을 때(경고·실패)의 안내 글은 그대로 뒀다. 긴 도움말(카메라·QR 안내) 두 곳은 한 줄로 줄이거나 뺐다.
- 버튼 이름: 「소리 들어 보기」→「한국어 듣기」, 「English voice」→「English」, 카드 제목 「카메라로 QR 읽기」→「카메라」, 「인터넷 없이 고유 일련 번호 화면 열기 (휴대전화)」→「인터넷 없이 열기」.
- CSS: `.dc-*` 규칙은 `components.css` 한 곳으로 모았다. `devices.css`의 `.device-check` 규칙은 지웠다(그 클래스를 쓰는 곳이 없어졌다). 새 CSS 파일, `!important`, 색 코드 없음. 낮은 화면(`max-height: 700px`)에서는 여백·아이콘 칩·QR 크기를 줄였다.
- e2e 가 쓰는 `.dc-item`(6개), `.dc-qr svg`, 「다시 확인」, 「카메라 켜기」, 인터넷 응답 문구는 그대로다.

## 크기별 실측 (doc/vh, 바꾸기 전 → 뒤). 옆 넘침 없음
| 크기 | 전 | 후 |
|---|---|---|
| 390×844 | 1885/844 | 1798/844 |
| 1280×633 | 1751/633 | 633/633 |
| 1333×750 | 1751/750 | 750/750 |
| 1366×657 | 1751/657 | 657/657 |
| 1920×937 | 1751/937 | 937/937 |
| 1920×1080 | 1751/1080 | 1080/1080 |
| 1024×768 | 1751/768 | 768/768 |
| 1080×1920 | 1920/1920 | 1920/1920 |
| 768×1024 | 재지 않음 | 1024/1024 |

- 바와 덩어리 끝선: 뒤에는 모든 크기에서 같다(예: 1333 폭 바 13–1306 = 카드 13–1306).
- 원자료: `measure-before.json`, `measure-after.json`.
- 키오스크 크기는 키오스크로 설치하지 않은 보통 브라우저에서 쟀다. 키오스크 설치 상태(`html[data-kiosk]`, 글자 기준이 커짐)에서는 재지 않았다.

## 점검
- tsc 통과, eslint 오류 0(경고 3개는 기존), vitest 1006 통과·5 건너뜀
- layout-check: 132개 화면, 문제 0개(이 화면은 점검 목록에 없다)
- e2e: 289 통과 / 289, 실패 0

## 남은 문제
- 휴대전화(390)는 카드가 한 줄로 쌓여 길다(1798). 허용 범위이지만 더 줄일 수 있다.
- 카메라를 켠 상태(영상이 보일 때)와 글자 1.5배는 재지 않았다. 카메라를 켜면 카드가 커져 스크롤된다.
- 소리·카메라 문제가 있는 기기의 경고 글(길다)이 나올 때의 모양은 그림으로 확인하지 못했다.
