# UI 정리와 현장 기기 진입

모바일은 두 열 서비스 카드와 간결한 요청 화면, PC는 일정한 콘텐츠 폭과 정렬된 작업 공간을 사용한다. 해바라기·초록·민트·노랑 아이덴티티는 유지한다.

- 공개 도움 요청에서 언어·글자 크기 도구를 헤더 하나로 합쳤다. 언어 변경은 작성 내용과 접수 상태를 유지한다.
- 요청 화면의 중복 상태 패널을 제거하고 입력 영역을 넓혔다. 장소 후보의 접근성 그룹을 명시했다.
- 메인 카드의 설명·필터를 줄였다. 전체 검색·필터·업무 설명은 서비스 찾기에서 이용한다.
- 사진 설명은 펼침 영역으로 옮겼다. 실제 출동이 없는 시연이라는 표시, 개인정보·동의, 오류·처리 상태는 유지한다.
- `/devices`에서 안내로봇과 안내 키오스크를 찾을 수 있다. 공개 미리보기는 예시 화면이며 서버 접수를 만들지 않는다.
- `/kiosk?use=entry`, `/kiosk?use=guide`는 기존 설치 인증을 유지하며, 설치 목적을 미리 선택한다. 설치된 `/kiosk/entry`, `/kiosk/guide` 흐름도 유지한다.
- 기존 로봇의 파란 테마를 공통 초록으로 바꿨다. 실물 로봇 연동을 추가한 변경은 아니다.

`scripts/ui-layout-e2e.ts`는 360·390·768·1024·1440·1920px 주요 화면, 모바일 메뉴, 언어 변경 중 입력 유지, 큰 글씨, 접근성, 직원 화면, 설치된 키오스크의 도구 겹침을 검사한다. 로컬 격리 서버와 공개 시드 코드만 사용한다.
