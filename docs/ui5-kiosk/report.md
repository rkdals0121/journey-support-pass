# UI_5 키오스크 화면 검증

## 바꾼 화면

- `/kiosk/entry`: 처음·번호/탑승권 조회·등록 확인·현장 질문·서류·동의·서비스 화면을 공통 틀로 구성했습니다. 조회 입력을 별도 단계로 열어 본문이 길어지지 않게 했습니다.
- `/kiosk/guide`: 등록 확인·서비스·맞춤 안내에 홈 화면의 소개 박스와 흰 카드, 아이콘 칩, 딥그린 버튼을 적용했습니다.
- 등록 내역은 네 항목씩, 시설은 두 곳씩 페이지를 넘겨 확인합니다. 항목과 기능은 유지했습니다. 긴 메모도 나눠서 모두 확인할 수 있습니다.
- 좁은 화면의 상단 바는 도움 버튼의 오른쪽 위 위치를 유지하면서 나머지 버튼을 아래로 감쌉니다.

## 크기별 실측 (바꾸기 전 → 뒤)

- 변경 후: 12개 화면 × 11개 크기 × 글자 1·1.5배 = 264건. 자바스크립트 오류 0건, 가로 넘침 0건.

## 확인 못 한 것 / 남은 문제

- 768×1024 태블릿의 입구 첫 화면은 글자 1.5배에서 1189/1024로 세로 스크롤 165px이 남습니다. 같은 조건의 맞춤 안내 화면은 1048/1024로 24px이 남습니다. 휴대전화도 세로 스크롤이 있습니다. 가로 넘침은 없습니다.
- 실제 키오스크 카메라·조명·터치 장비와 OS 배율을 적용한 물리 화면은 확인하지 않았습니다. 카메라 검사는 Chrome의 가상 카메라와 시험용 QR을 사용했습니다.
- 264건의 화면 실측은 한국어 정상 항공편 기준입니다. 영문·탑승구 미정·다른 터미널·결항 등 흐름은 전체 e2e로 확인했으며, 모든 변형을 모든 크기로 실측한 것은 아닙니다.
- Vercel 미리보기: 미리보기에서의 직접 확인은 아직 하지 않았습니다..
- 새 외부 자료나 DB 구조 변경은 없습니다. 기존 저장소의 하늘이 그림을 재사용했습니다.
