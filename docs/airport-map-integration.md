# 공통 시설 터치 지도 연결

`/help?topic=mobility`는 큰 메뉴 네 개로 시작한다. 길 안내는 `/navigate`, 전동차 타기는 직원 지원 요청(`flow=staff`), 하늘이 동행은 저니봇 안내(`flow=robot`), 내 신청은 기존 요청 조회로 연결한다.

`/navigate`와 이동 도움의 지도 화면은 `AirportRoutePlanner` → `FacilityMapPicker` → `AirportMap`을 함께 사용한다. 지도는 화면을 채우고 검색·출발지·목적지·서비스 작업은 옆 패널에 배치한다. 좁은 화면과 세로 키오스크에서는 패널 배치를 조정한다. 기존 공통 상단 바는 유지한다.

## 이동 도움받기

탑승구뿐 아니라 지도에 등록된 시설을 출발지로 선택할 수 있다. 선택한 시설 ID와 이름을 요청 확인·접수·조회·직원 목록에 유지한다. 출발지 선택 가능 여부와 지도 표시를 분리하여 시설이 숨겨지지 않게 한다. 현재 위치 버튼은 등록된 키오스크 위치를 복원한다. 위치가 없으면 버튼을 비활성화하며 좌표를 추측하지 않는다. 지도에 연결되지 않는 기존 위치는 목록·사진 입력으로 담당자에게 전달한다.

현장 안내는 장소 선택 → 필요한 도움 → 요청 확인의 직원 지원 절차이다. 전동차 타기로 들어오면 차량 지원이 미리 선택된다. 하늘이 동행은 출발지·목적지 → 경로 확인 → 안내 시작 → 수동 목적지 도착 확인 → 안내 종료의 시연 절차이며, 중복된 현장 안내/저니봇 선택란을 표시하지 않는다. 실제 로봇 이동이나 자동 도착 감지를 연결하지 않는다. 직원의 휠체어 수령 업무에는 목적지를 지정하지 않는 기존 규칙을 유지한다.

다른 시설은 약국·수유실·어린이놀이시설·라운지·안심여행센터·AED·우대출구 등 17종의 큰 그림 카드로 제공한다. 현재 선택 가능한 터미널·보안구역의 시설 수를 표시하며 시설의 고유 분류와 이름을 기준으로 필터링한다.

## 표시와 경로

- 서비스 지도는 중앙 구역 배율 18.5로 시작하며 경로 전체 맞춤·전체 보기 조작은 유지한다.
- 주요 위치 → 필수 시설 → 편의 시설 → 전체 시설의 네 단계로 표시한다. 확대 기준은 16.5 / 18 / 19.5이다. 이름 충돌은 아이콘 표시와 별도로 처리한다.
- 검색·시설 필터에 일치하는 아이콘은 모든 확대 단계에서 표시한다. 방향 확인용 주요 위치는 회색 이름으로 남길 수 있다.
- 가까운 시설은 연결된 통로 거리로 최대 세 곳을 정렬한다.
- 같은 터미널·보안구역의 연결된 통로에 대해서만 경로를 계산한다. 출발지 변경으로 호환되지 않는 목적지는 해제한다.
- 실제 계단 없는 접근성, 다른 층 이동, 실제 로봇 이동 제어와 자동 도착 감지는 연결되지 않았다.

탑승구·시설 찾기의 키오스크/저니봇 시연 모드는 하나만 선택한다. 키오스크는 경로 확인 후 목적지 다시 선택 또는 처음 화면으로 돌아간다. 저니봇은 안내 시작 → 수동 도착 확인 → 안내 종료 순서이다.

## 데이터와 서버

시설 ID는 `map-poi-<원본 ID>`이며 `airport-facilities.json`에서 검증한다. 브라우저가 전송한 이름·좌표를 신뢰하지 않는다. 등록 탑승구 ID는 유지하며 가까운 거점으로 임의 변경하지 않는다. 시설 출발지는 이동지원 요청에만 허용한다. 운영 가능 여부도 시설의 터미널·보안구역으로 기존 운영 거점을 찾아 확인한다. DB 스키마 변경은 없다.

지도 iframe 경로에만 `X-Frame-Options: SAMEORIGIN`을 적용한다. 나머지 화면의 프레임 차단은 유지한다.

## 검증과 출처

최종 검사와 화면 자료는 [PR 검토 기록](pr-shared-airport-map.md)을 따른다. 과거 `*-review.md`는 단계별 작업 기록이며 현재 동작은 이 문서를 우선한다.

공식 지도 자료의 출처와 공개 재배포 허가 미확인 상태는 [THIRD_PARTY_NOTICES](../public/airport-map/THIRD_PARTY_NOTICES.md)를 따른다. 이번 변경이 제3자 자료의 이용 권한을 새로 부여하지 않는다. 만남 사전 예약과 실제 로봇 자동 이동은 이번 변경에 포함하지 않는다.
