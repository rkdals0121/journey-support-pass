# 만날 곳 변경과 담당자 확인

지원 전 위치가 바뀐 여객이 접수를 취소하고 새로 만들지 않아도 현재 요청에서 변경할 수 있도록 한다.

- 미배정: 여객의 확인값과 요청 버전을 검증한 뒤 만날 곳을 바로 수정한다.
- 배정·이동·도착: 변경 희망 지점을 별도로 보관하고 담당 구역 또는 안내데스크가 수락해야 확정한다. 확인 전에는 이동·도착·지원 시작과 장비 배차 변경을 차단한다.
- 수락: 담당과 배차를 유지하고 배정 단계로 돌아간다. 이전 도착·지원 시작 시각은 비우고 최초 배정 시각은 보존한다.
- 거절: 사유를 여객에게 표시하고 기존 확정 위치와 진행 단계를 유지한다. 여객은 변경 요청을 철회하거나 새 지점으로 다시 요청할 수 있다.
- 지원 시작 이후: 임의 위치 수정을 막고 현장 직원에게 직접 알리도록 안내한다.
- 공용 기기: 설치 위치는 바꾸지 않는다. 접수 확인 QR을 휴대전화에서 열어 변경하거나 안내데스크에 알리도록 안내한다.
- 동일 요청의 네트워크 재시도는 이력을 중복 생성하지 않는다. 다른 변경과 경합하면 버전 검사로 한 변경만 반영한다.
- 취소·지원 불가·시간 초과·정보 삭제는 대기 중 위치 정보도 정리한다. 위치 변경 이력의 상세 문구는 기존 24시간 삭제 규칙을 따른다.
- 사전등록의 요청 내역에도 위치 변경 확인 대기를 표시한다. 기존 호출·이동지원 원본의 위치를 소급 변경하지 않는다.

## 검증과 범위

담당 구역 권한, 경합·재시도, 인계, 도착 후 재배정, 배차 유지, 거절·철회, 취소·만료·정보 삭제, 이력 실패 시 롤백을 검사한다. 여객과 직원의 별도 브라우저에서 변경·수락·거절·철회·지원 시작 이후 안내 및 영어 사전등록 표시를 확인한다.

위치 목록과 이동 상태는 시범 자료다. 실제 장비를 자동 정지시키거나 운행 경로를 변경하지 않는다. 실제 장비와 운영 구역 연동에는 기관의 인터페이스와 운행 조건 확인이 필요하다.
