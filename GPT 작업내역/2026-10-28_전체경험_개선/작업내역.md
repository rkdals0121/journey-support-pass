# 서비스 전체 경험 개선 — 2026-10-28

## 사용자가 지적한 실제 화면
1. 메인: 홍보형 큰 녹색 박스와 빈 요청 현황이 실제 서비스 선택을 뒤로 밀고 있었다.
2. 키오스크: 6개 동일 비중 카드, 직원 도움 2곳, 소리 안내 2곳과 중복 위치 표기로 핵심 선택이 흐려졌다.
3. 예약 확인: 예약 거점과 정확히 일치하지 않는 기기에서 입력 자체를 막아, 홈 링크를 누르면 설명만 있는 막다른 화면이 나왔다.

## 변경
- 메인 소개를 가볍게 줄이고 경로 검색과 서비스 선택을 앞세움. 요청이 없으면 빈 현황 영역은 표시하지 않음.
- 여객 상단 메뉴에서 기기 설치/시연 항목을 제외. 하단 기기 링크는 보존.
- 공통 서비스 선택은 길 찾기·이동 지원 우선, 시설·교통·기타는 보조. 로봇 모의 체험은 전체 서비스 목록과 전용 기기 화면에서 접근 가능.
- 설치된 키오스크의 직원 도움은 상단 1곳으로 통합. 중복 버튼과 위치 문구 제거.
- 모든 설치 기기에서 오늘의 예약 확인번호를 입력할 수 있게 함. 다른 거점 예약이면 장소·시각·지도만 제공하고, 개인정보·예약 capability·처리 상태는 노출하지 않음. 실제 도착/응대는 해당 거점 기기에서만 허용.
- 내 요청의 예약 목록을 본문 제목 다음에 배치. 직원 예약 화면은 접수 화면과 같은 제목/도구 구조 사용.
- 시설 신고의 과도한 경고 배경 제거. 개인정보 입력 제한 내용은 보존.

## 근거
- API 관련 통합 검사 21개 통과. 다른 거점/거점이 아닌 실제 기기(t2-west)에서 위치만 반환하고 도착 처리 불가 검사 포함.
- 첫 브라우저 검사 32화면+예약 연결 흐름 1개 통과, 넘침/자동 WCAG 위반/JS 오류 0. 입력 없는 화면을 실제 입력→장소 안내→도착 확인 흐름으로 확인.
- 화면을 직접 본 뒤 빈 요청 현황과 키오스크 중복 도구를 추가 수정. 최종 빌드 후 다시 시각 확인/회귀 검사 예정.
- 운영 접수·알림을 만들지 않는 격리 로컬 환경 사용. 예약 시간 검증에는 테스트 전용 15:45 시계 사용. 운영 시계는 변경하지 않음.

완성 판단은 테스트 개수가 아니라 실제 화면의 목적과 연결된 작업 흐름을 함께 근거로 한다. 기존 서버 결함 수정과 이번 UI/UX 개선을 같은 완료 결과로 혼동하지 않는다.
